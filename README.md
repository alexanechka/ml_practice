## ML Service — Личный кабинет пользователя

Учебный проект: веб-сервис с личным кабинетом пользователя, предоставляющий доступ к ML-модели через Web, REST API и Telegram-бота. Списание кредитов за успешные запросы, история предсказаний, роли пользователь/администратор.

**Суммаризация текста (summarization)** — пользователь загружает текст (например, статью, отзыв, описание), сервис возвращает краткий пересказ.

- Модель: `gemma3:1b` (Ollama) — одна многоязычная модель, обслуживает и английский, и русский текст
- Вход: текст запроса через Web-интерфейс или REST API (одно предсказание = один запрос = одно списание кредита)
- Выход: текст пересказа, статус задачи, количество списанных кредитов

## Запуск

1. Поднять весь стек:
   ```bash
   docker compose up -d --build
   ```
2. Загрузить модель в Ollama (разово, веса сохраняются в volume и переживают пересоздание контейнера):
   ```bash
   docker exec ml_service_ollama ollama pull gemma3:1b
   ```
3. Проверить, что всё поднялось:
   ```bash
   docker ps
   ```
   `ml_service_app` должен быть в статусе `healthy`.
4. Открыть:
   - Web-интерфейс: http://localhost:8501
   - REST API / документация: http://localhost/api/docs

### Тесты

```bash
pip install -r tests/requirements.txt
pytest tests/ -v
```
Тесты бьют в `http://localhost/api`, поэтому стек должен быть поднят и доступен перед запуском.
