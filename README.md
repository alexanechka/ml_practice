# m# ML Service — Личный кабинет пользователя

Учебный проект: веб-сервис с личным кабинетом пользователя, предоставляющий доступ к ML-модели через Web, REST API и Telegram-бота. Списание кредитов за успешные запросы, история предсказаний, роли пользователь/администратор.l_practice

**Суммаризация текста (summarization)** — пользователь загружает текст (например, статью, отзыв, описание), сервис возвращает краткий пересказ.

- Модель (open source, pretrained, без дообучения):
  - `sshleifer/distilbart-cnn-12-6` — для английского текста
  - `IlyaGusev/rut5_base_sum_gazeta` — для русского текста
- Библиотека: `transformers` (HuggingFace), `pipeline("summarization", model=...)`
- Вход: CSV со столбцом `text` (одна строка = один текст = один запрос = одно списание кредита)
- Выход: столбец `summary`, статус, количество списанных кредитов
